# 🐤 Flappy Bird Mod (React + TypeScript)

This is a fun **modded version of the original Flappy Bird game**, built using **React, TypeScript, and Vite**.  
The goal of this project is to recreate the simple but addictive gameplay of Flappy Bird and slowly add modern features like:

✅ New background themes  
✅ Sound effects  
✅ Score system  
✅ Login-based high scores (coming soon!)

---

## 🚀 Features

### ✅ Currently Available
- Smooth gameplay using React + Canvas  
- Gravity, jump, and collision mechanics  
- Pipes with random height and gaps  
- Responsive design  
- Basic score system (coming soon / may already exist depending on your latest commits)

### 🛠 Upcoming Features
- 🔐 Login + user-based score tracking  
- 💾 Store high scores in database  
- 🎵 Sound effects (jump, score, game over)  
- 🌄 Dynamic background images / themes  
- 📱 Mobile-friendly UI and touch controls

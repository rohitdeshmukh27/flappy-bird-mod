# 🐤 Flappy Bird Mod

This project is a completely unserious, gloriously chaotic little remix of Flappy Bird built with React + TypeScript for pure entertainment purposes only.

No grand vision.
No strategic roadmap.
No deep existential bird analytics.
Just a tiny game, some pipes, a few vibes, and a whole lot of "why not?"

This repo is here to entertain, amuse, and maybe mildly distract you from your actual responsibilities. Please do not take it too seriously.

---

## 🎮 What is this?

A playful browser game inspired by the classic Flappy Bird formula:

- Tap, click, or press space to flap
- Avoid the pipes
- Survive long enough to pretend you have talent
- Watch the score climb while your dignity declines

In short: a bird, a gap, a little chaos, and a lot of optimism.

---

## 😎 Why this exists

Because someone wanted to build a silly game, and the internet said, "Go ahead, weird little champion."

This project is for:

- fun
- experimentation
- pixel-powered nonsense
- making a bird look brave in the face of danger
- absolutely zero business value

---

## ✨ Features

### Currently included
- Smooth side-scrolling gameplay
- Gravity + flap controls
- Randomized pipe gaps
- Score tracking
- Responsive layout
- Visual flair and mod vibes
- A lot of energy

### Probably coming soon
- More dramatic bird behavior
- A "legendary" score screen
- Background themes that may or may not make sense
- Secret easter eggs
- Extra nonsense because why not

---

## 🚀 Run it locally

```bash
npm install
npm run dev
```

Then open the local dev server in your browser and begin your journey as a tiny bird with questionable life choices.

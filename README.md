# 🐤 Flappy Bird Mod

![Flappy Bird Mod game background](public/images/background.jpg)

A playful Flappy Bird-inspired browser game built with React and TypeScript. Tap, click, or press **Space** to flap, dodge the pipes, and see how long you can keep your dignity intact.

## ✨ Features

- Side-scrolling gameplay with gravity and flap controls
- Randomized pipe gaps
- Score tracking
- Responsive layout
- Optional game sounds and background music

## 🚀 Run it locally

```bash
npm install
npm run dev
```

Open the local development server in your browser and start flapping.
